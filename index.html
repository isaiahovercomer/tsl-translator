🗂 收集模式：幫忙錄手語語料

畫面出一個詞（或一句），對著手機前鏡頭比 3 次，自動換下一個。只存骨架點、不存影像，用來訓練手語辨識，讓翻譯越來越準。最需要：召會用語（辭典沒有的）。

鏡頭錄製、上傳影片、網址匯入都會存到這個分類（切段時也可以個別改）。

📷 用鏡頭錄一個詞

按「開始錄」，倒數 3 秒後比一次；手放下會自動停止

每個詞建議錄 5 次以上、請不同的人錄，辨識會更準。只存骨架點，不存影像。不確定怎麼比，先按「📖 查辭典」看台灣手語線上辭典（中正大學，4600 詞），再照著錄。

🎞️ 上傳影片檔

手機或電腦裡的手語影片都可以。在這台裝置上分析成骨架資料，影片不會上傳、也不會保存。

🔗 網址匯入（YouTube）

方法一：邊播邊擷取（電腦版 Chrome／Edge）。① 開啟影片 → ② 開始擷取，選那個影片分頁 → 回去按播放 → 播完按「停止擷取」。在你的電腦上即時轉成骨架，不下載影片。

方法二：送到雲端分析

會開啟 GitHub 頁面，按「Submit」送出；雲端下載影片、抽出骨架、刪掉影片。注意：YouTube 常擋雲端主機，需要管理員先在 repo 設定 YouTube 登入資料（YT_COOKIES）。

同義說法

口語說法對應到語料庫的手語詞，一行一個，例如 您好=你好、多謝=謝謝。

📖 使用說明

  1. 開始對話：在「對話」按「▶ 開始對話」，把手機立起來（可靠在杯子或手機架上），螢幕和前鏡頭對著聽損者。
  2. 聽人說話：在手機旁邊正常說話，講完一句稍停一下；字幕出現在下方，手譯員把它比成台灣手語。左上角「🎤 聽到聲音」亮起，表示手機有收到。
  3. 聽損者比手語：對著鏡頭比，左上角「📷 看到手」亮起表示有拍到。比慢一點、詞和詞之間手稍停；每個手勢會留 3 個候選詞，一句比完（手放下或停一下）由 AI 挑出最通順的句子再唸出來。先選好情境（寒暄常用／聚會／召會生活），只在常用詞裡找，比較準也比較快。
  4. 會議一直講：手譯員會照順序一句一句比；按 ⏸ 暫停、⏭ 跳下一句。字太小可按「Aa」放大。
  5. 認錯的手語詞（紅色）可以在「分開操作」裡點一下改成正確的詞。

語料庫已有中正大學台灣手語線上辭典約 3,500 個詞，還可以自己錄、上傳影片或貼 YouTube 網址增加（「新增語料」）。

以台灣手語（自然手語）為主。手語的詞序和中文不同，會先用 AI 調整成台灣手語語序再比（設定裡可改）。

隱私：所有影片只在裝置上（或雲端分析時暫存）轉成骨架點，原始影像不保存。

建議用 Chrome（Android／電腦）。iPhone 請用 Safari，並「加入主畫面」。重新看使用說明

🗂 收集模式

每個人比的方式都有點不同，越多人錄、辨識越準。錄的時候只存手、身體、臉的骨架點（看不出是誰），不存影像。

小提醒：手機直立放好、上半身和雙手都要入鏡；手放下＝準備，舉手＝開始錄，比完手放下＝錄好。比錯了按「↺ 重錄」。
